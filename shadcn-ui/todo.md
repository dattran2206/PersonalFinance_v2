# Personal Finance Management App - MVP Implementation

## Core Features to Implement:
1. **Authentication Pages** - Login/Register forms
2. **Dashboard** - Overview with charts and quick stats
3. **Wallets Management** - View, add, edit wallets and transfers
4. **Transactions** - Add income/expense with categories
5. **Budgets** - Set and track spending limits
6. **Goals** - Savings goals with progress tracking
7. **Debts** - Track borrowed/lent money
8. **Reports** - Charts and summaries

## Files to Create:
1. `src/pages/Index.tsx` - Main dashboard (rewrite existing)
2. `src/pages/Login.tsx` - Authentication page
3. `src/pages/Wallets.tsx` - Wallet management
4. `src/pages/Transactions.tsx` - Transaction history and add new
5. `src/pages/Budgets.tsx` - Budget management
6. `src/pages/Goals.tsx` - Savings goals
7. `src/pages/Debts.tsx` - Debt tracking
8. `src/components/Layout.tsx` - Main app layout with navigation

## Key Components:
- Navigation sidebar
- Dashboard cards with stats
- Transaction forms
- Charts for reports
- Responsive design with dark mode
- Mock data for demonstration

## Tech Stack:
- React + TypeScript
- Tailwind CSS + shadcn/ui components
- Recharts for data visualization
- LocalStorage for demo data persistence
